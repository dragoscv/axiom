All `@codai/axiom-*` packages form one **fixed Changesets group**: they share a single
version and are published together on every `v*` tag by
[`release.yml`](.github/workflows/release.yml) (npm trusted publishing, provenance).
Per-package history is generated by Changesets into each package's own changelog;
release notes with the full asset list (binaries, `SHA256SUMS`, `.vsix`) live on GitHub Releases.

## 2.2.1 (2026-09-21) — Phase 5: distribution, docs site, repo polish

No wire or API change. Standalone binaries for linux-x64, linux-arm64, darwin-arm64,
darwin-x64 and win-x64 (Node 26 single-executable, built natively per target) are attached
to every release with `SHA256SUMS` and Sigstore build provenance; `install.sh` / `install.ps1`
are served from the docs site. The server is listed on the MCP Registry as
`io.github.dragoscv/axiom`, and the composite action gains a moving `dragoscv/axiom/action@v2`
tag. The documentation moves to an Astro Starlight site at
<https://dragoscv.github.io/axiom/>, the root README/SUPPORT/SECURITY/CHANGELOG are rewritten
for v2, and community health files (Code of Conduct, issue/PR templates, CODEOWNERS,
Dependabot, `CITATION.cff`, OpenSSF Scorecard) are added. `expr.cedar` fails closed inside a
SEA when the optional Cedar WASM is absent. Decisions D-27…D-31 in [PLAN.md](PLAN.md).
